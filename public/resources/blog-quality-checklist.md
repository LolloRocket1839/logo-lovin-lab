# 📋 Checklist Qualità Articoli Blog - Jungle Rent

Guida interna per valutare la qualità degli articoli prima e dopo la pubblicazione.
Basata su dati analytics reali e best practices SEO.

---

## 📝 SEZIONE A: Contenuto (Pre-Pubblicazione)

| ☐ | Criterio | Dettagli | Peso |
|---|----------|----------|------|
| ☐ | **Titolo** | < 60 caratteri, include keyword principale | ⭐⭐⭐ |
| ☐ | **Meta description** | 150-160 caratteri, call-to-action implicita | ⭐⭐⭐ |
| ☐ | **Excerpt** | Accattivante, max 25 parole | ⭐⭐ |
| ☐ | **Immagine hero** | Ottimizzata < 200KB, alt text descrittivo | ⭐⭐ |
| ☐ | **ReadTime** | Realistico (calcolo: 250 parole/minuto) | ⭐ |
| ☐ | **FAQs** | Almeno 5-10 domande con risposte complete | ⭐⭐⭐ |
| ☐ | **Tags** | 4-6 tag pertinenti e ricercabili | ⭐⭐ |

**Punteggio massimo Sezione A: 20 punti**

## ✍️ SEZIONE B: Stile di Scrittura

### Bandiere Rosse AI-Style (da evitare)

| ☐ | Criterio | Bandiera Rossa |
|---|----------|----------------|
| ☐ | Nessun **em dash (—)** nel testo | 🚩 AI-style |
| ☐ | Frasi < 25 parole in media | 🚩 AI-style |
| ☐ | No costruzioni ridondanti | 🚩 AI-style |
| ☐ | Tono conversazionale, non accademico | 🚩 AI-style |
| ☐ | Uso di "tu/voi" invece di forme impersonali | 🚩 AI-style |
| ☐ | Paragrafi brevi (max 4 frasi) | 🚩 UX |
| ☐ | Sottotitoli H2/H3 ogni 300-400 parole | 🚩 SEO |

### Frasi da evitare (tipiche AI)

```
❌ "È importante notare che..."
❌ "In questo articolo esploreremo..."
❌ "Andiamo a scoprire..."
❌ "Senza ulteriori indugi..."
❌ "In conclusione, possiamo affermare che..."
❌ "Come abbiamo visto in precedenza..."
❌ "Vale la pena menzionare che..."
❌ "Detto questo, procediamo..."
```

### Stile preferito

```
✅ Frasi brevi e dirette
✅ Domande retoriche per coinvolgere
✅ Esempi concreti e locali
✅ Numeri e dati specifici
✅ Citazioni di luoghi reali
✅ Tono da "amico esperto"
```

**Punteggio massimo Sezione B: 15 punti**

## 🔍 SEZIONE D: SEO Checklist

| ☐ | Criterio | Note |
|---|----------|------|
| ☐ | Keyword principale nel titolo H1 | Posizione iniziale preferita |
| ☐ | Keyword in almeno 2 sottotitoli H2 | Naturale, non forzato |
| ☐ | Keyword density 1-2% nel corpo | Usare sinonimi e variazioni |
| ☐ | Link interni (almeno 2-3) | Ad altri articoli correlati |
| ☐ | Link esterni (1-2) | Fonti autorevoli, aprire in nuova tab |
| ☐ | Immagini con alt text | Contenere keyword dove naturale |
| ☐ | URL slug pulito | Breve, descrittivo, senza date |
| ☐ | Schema FAQ | Implementato per rich snippets |

## 🎯 Sistema di Scoring

### Calcolo Punteggio

| Sezione | Punti Max |
|---------|-----------|
| A - Contenuto | 20 |
| B - Stile | 15 |
| D - SEO | 15 |
| E - Localizzazione | 10 |
| **TOTALE** | **60** |

### Valutazione Finale

| Score | Valutazione | Azione |
|-------|-------------|--------|
| 50-60 | ✅ **Eccellente** | Pubblica immediatamente |
| 40-49 | 🟡 **Buono** | Piccole revisioni, poi pubblica |
| 30-39 | 🟠 **Da migliorare** | Revisione sostanziale necessaria |
| < 30 | 🔴 **Insufficiente** | Richiede riscrittura |
