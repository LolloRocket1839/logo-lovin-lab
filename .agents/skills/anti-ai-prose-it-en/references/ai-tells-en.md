# AI tells in English — patterns to avoid

## Punctuation

| Avoid | Use |
|---|---|
| — (em-dash) | comma, colon, period, parentheses |
| Ellipsis (...) as rhetorical pause | period |

## Rhetorical constructions

| Avoid | Rewrite as |
|---|---|
| It's not X, it's Y. | It's Y, rather than X. (or just: It's Y.) |
| Not only X but also Y | X and Y. |
| Not just X — Y | X, and Y. |
| On one hand X. On the other Y. | Use at most once per article. |
| Three negatives in a row ("not lived in, not rented, not maintained") | Positive adjectives ("empty, unrented, neglected") |

## Filler / hedge phrases (DELETE)

- In other words
- It's worth noting that
- It's important to note that
- That said
- Needless to say
- In conclusion / To sum up
- At the end of the day
- When all is said and done
- It goes without saying
- As mentioned earlier
- In today's world / In today's fast-paced world
- In the modern era

## AI-coded vocabulary

| Avoid | Prefer |
|---|---|
| delve into | look at, examine |
| navigate (metaphorical) | handle, deal with |
| leverage (as verb) | use |
| landscape (as filler) | market, scene |
| ecosystem (outside actual tech) | network, system |
| synergies | (rewrite without) |
| robust / solid (as filler) | (delete) |
| seamless | smooth, simple |
| streamline | simplify |
| harness | use |
| unlock (as filler) | (delete or be concrete) |
| empower | help, enable |
| cutting-edge | (delete unless literally true) |
| game-changing | (delete) |
| revolutionize | change |
| holistic | complete, whole |
| pivotal / crucial / essential (as filler) | (delete) |

## Paragraph openers to avoid

- "Moreover, …"
- "Furthermore, …"
- "Additionally, …"
- "Consequently, …"
- "Thus, …"
- "Indeed, …"

Replace with no connector, or "And", "But", "So", "Still".

## Sentence length

- Target average: **<25 words**.
- If a sentence has 3+ subordinate clauses, split it.

## Real examples from `real-life-monopoly` (before → after)

| Before | After |
|---|---|
| "has already begun — and what it means" | "has already begun, and what it means" |
| "Not just any homes: largely large apartments" | "These are largely large apartments" |
| "It's not an isolated figure" | "The figure is confirmed elsewhere" |
| "idle — not lived in, not rented, not maintained" | "idle: empty, unrented, left without maintenance" |
| "It's not speculation on resale. It's active management" | "This is active management of a real asset, rather than a resale play" |
