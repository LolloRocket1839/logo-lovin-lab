# AI tells in italiano — pattern da evitare

Lista dei pattern che fanno suonare il testo "AI" in italiano. Per ognuno, una sostituzione naturale.

## Punteggiatura

| Evitare | Usare |
|---|---|
| — (em-dash) | virgola, due punti, parentesi, punto |
| … (puntini di sospensione) come pausa retorica | punto fermo |
| "virgolette curly" miste con "diritte" | uniforme nel file |

## Costruzioni retoriche

| Evitare | Riscrivere come |
|---|---|
| Non è X. È Y. | È Y, non X. (oppure: È Y.) |
| Non solo X, ma anche Y | X e Y. (oppure: X, e in più Y.) |
| Non per X, ma per Y | L'obiettivo è Y. |
| È X, ma anche Y | È X e Y. |
| Da una parte X. Dall'altra Y. | Usa una volta sola per articolo, mai due. |
| Tre negativi in fila ("non abitati, non affittati, non manutenuti") | Aggettivi positivi ("vuoti, sfitti, abbandonati") |

## Filler / hedge

| Evitare | Sostituire / cancellare |
|---|---|
| In altre parole | (cancella, la frase dopo deve bastare) |
| Vale la pena notare che | (cancella) |
| È importante sottolineare che | (cancella) |
| Va detto che | (cancella) |
| In conclusione / In sintesi | (cancella, chiudi con una frase forte) |
| Per così dire | (cancella) |
| In un certo senso | (cancella o sii più preciso) |
| Come accennato | (cancella) |

## Parole "AI-coded"

| Evitare | Preferire |
|---|---|
| approfondire | guardare, esaminare |
| navigare (metaforicamente) | affrontare, gestire |
| sfruttare appieno | usare |
| panorama (es. "panorama immobiliare") | mercato, scenario |
| ecosistema (fuori da contesto tech reale) | rete, sistema |
| sinergie | (riscrivi senza) |
| strategico (come riempitivo) | (cancella o sostituisci con verbo concreto) |
| robusto / solido (come riempitivo) | (cancella) |
| innovativo (su tutto) | usa solo se concretamente nuovo |
| nel mondo di oggi / nell'era attuale | (cancella) |

## Apertura di paragrafo

| Evitare apertura | Preferire |
|---|---|
| "Inoltre, …" | continua il filo, niente connettore |
| "Tuttavia, …" | "Ma " o frase nuova |
| "Pertanto, …" | "Quindi" o omesso |
| "Di conseguenza, …" | "Risultato:" o frase diretta |

## Lunghezza frase

- Media target: **<25 parole**.
- Se una frase supera 30 parole o ha 3+ subordinate, spezzala.

## Esempi reali da `real-life-monopoly` (prima → dopo)

| Prima | Dopo |
|---|---|
| "è già cominciata — e cosa significa" | "è già cominciata, e cosa significa" |
| "Non case qualsiasi: in larga parte abitazioni grandi" | "Sono in larga parte abitazioni grandi" |
| "Non è un dato isolato" | "Il dato trova conferma altrove" |
| "fermi — non abitati, non affittati, non manutenuti" | "fermi: vuoti, sfitti, lasciati senza manutenzione" |
| "Non è speculazione sulla rivendita. È gestione attiva" | "È gestione attiva di un asset reale, non un'operazione di rivendita" |
